## zone configuration

- **Immersion Room:** Tablet `TAB-9003-01` controls curved LED `LED-9003-01` via NUC `NUC-9003-01`, Brightsign `BS-9003-01`, and processor `PROC-9003-01`
- **Floorplate zone:** Tablet `TAB-9003-02` controls floorplate LEDs `LED-9003-03/04` via NUC `NUC-9003-02` and processor `PROC-9003-02`
- **Neighbourhood Map zone:** Touchscreens `TCH-9003-01/02` standalone (no tablet control)
- **Reception zone:** Tablet `TAB-9003-03` controls display `SCR-9003-01`
- **External window:** External LED `LED-9003-02` driven by Brightsign `BS-9003-02`, on/off via control gateway `GW-9003-01`
- **Audio routing:** NUC + tablet sources → Submixer `MIX-9003-01` → DSP `DSP-9003-01` → Amp `AMP-9003-01` → 6 ceiling speaker zones
- **Lighting zones:** Architectural model (5 spotlight zones), suite ambient (3 zones)
